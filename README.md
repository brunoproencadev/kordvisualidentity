Uma apresentação de Diretrizes Executivas de Marca interativa e de vanguarda para o ecossistema **kord**. Este projeto funciona como um *Brand Book* digital, documentando a estratégia, cultura, tokens de design, arquitetura tipográfica e regras de uso de logos da marca.

## 🚀 O Projeto

A kord nasceu com o propósito: **work less, earn more**. 
O design traduz a elegância, inovação e a conexão sem ruídos propostos pela empresa. O site foi construído para passar uma sensação de aplicativo nativo (Glassmorphism), com foco absoluto na fluidez e microinterações. 

⚠️ A **kord** **não** é uma empresa real, é uma empresa fictícia criada para fins acadêmicos

### Principais Seções
- **Estratégia**: Semântica, Missão e Visão.
- **Cultura**: Nossos 5 valores inegociáveis.
- **Sistema Cromático**: Paleta de cores oficial (Midnight Blue, Warm White, Matte Slate).
- **Tipografia**: Sistema hierárquico da família *Anthropic Sans*.
- **Arquitetura da Marca**: Assinaturas primárias, horizontais, wordmarks e avatares.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias puras do desenvolvimento web para garantir o máximo de performance e customização, sem dependência de frameworks pesados:

- **HTML5**: Estruturação semântica em formato de slides.
- **CSS3 (Vanilla)**:
  - Estilização premium baseada em *Glassmorphism* (efeitos de vidro).
  - Animações e Shaders fluídos (Distorção Magnética).
  - Design Responsivo e Variáveis CSS (Design Tokens).
- **JavaScript (Vanilla)**: Lógica de controle do slider (scroll, teclado, cliques).
- **GSAP (GreenSock)**: Biblioteca core responsável por todas as animações de entrada e transições suaves entre os slides.

## 📂 Estrutura do Projeto

Para garantir manutenibilidade e escalabilidade, o código foi separado seguindo boas práticas de desenvolvimento:

```text
📦 kordvisualidentity
 ┣ 📂 css
 ┃ ┗ 📜 style.css       # Variáveis Globais, Reset, Glassmorphism e Layout
 ┣ 📂 js
 ┃ ┗ 📜 main.js         # Lógica de Sliders, GSAP animations e Shader Magnético
 ┣ 📜 index.html        # Estrutura do projeto, SVGs e marcação
 ┗ 📜 README.md         # Documentação do projeto
```

## ⚙️ Como executar o projeto localmente
Como o projeto é estático (Vanilla HTML/CSS/JS), não é necessário instalar dependências com o Node.js.

**Faça o clone do repositório:**
```bash
git clone https://github.com/brunoproencadev/kordvisualidentity.git
```
**Abra a pasta do projeto:**
```bash
cd kordvisualidentity
```
Execute o index.html no seu navegador favorito. Recomendamos utilizar a extensão Live Server (do VS Code) para ter a melhor experiência de desenvolvimento.
